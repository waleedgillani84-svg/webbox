# WebBox -- HTML & Website Manager (Progressive Web App)

Offline-capable PWA ready for **GitHub Pages** deployment.

## 🚀 How to Deploy on GitHub Pages

1. **Create Repository:** Create a new repo on GitHub (e.g., `webbox --`).
2. **Upload Files:** Upload all generated files (`index.html`, `manifest.json`, `sw.js`, `README.md`, `icon-192.png`, `icon-512.png`) to the root.
3. **Enable GitHub Pages:** **Settings → Pages → Deploy from a branch** (`main` / `root`).
4. **Access App:** `https://<username>.github.io/<repo>/`
